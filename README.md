StegoScan is an automated steganography analysis tool designed to help cybersecurity beginners quickly analyze files for hidden content. This powerful Bash script scans files using multiple steganography techniques and generates a comprehensive report with extracted artifacts.

**Perfect for CTF challenges, red team operations, and cybersecurity training!**

## Why I Built This

As a cybersecurity beginner:
- 😓 I struggled with steganography challenges in CTFs
- ⏳ Wasted time running tools manually
- 🤯 Got confused by different tool outputs
- 💡 Created this to automate the process
- 🙏 Seeking mentorship to improve it!

## Key Features

- **Beginner-friendly** - Simple interface, no complex setup
- **Automated scanning** - Single command analysis
- **Comprehensive reports** - All findings in one place
- **Artifact extraction** - Saves discovered content
- **Password support** - Test passwords for protected content
- **Brute-force mode** - Crack passwords with wordlists
